# Criei um guia prático de DevOps para iniciantes

Quando comecei a explorar DevOps, encontrei muita documentação útil — mas espalhada por dezenas de páginas, vídeos e ferramentas. Faltava-me um recurso simples que ligasse os conceitos e mostrasse uma sequência prática para começar.

Por isso, criei um guia gratuito e orientado para iniciantes.

O percurso essencial passa por Linux, SSH, Docker, Docker Compose, PostgreSQL básico, CI/CD, segurança e termina no conceito de reverse proxy. Para quem quiser continuar, inclui ainda uma parte opcional com configuração de Nginx, TLS, base de dados e deployment num VPS.

Os conceitos são aplicados progressivamente no WebFusionLab: Dockerfile multi-stage, utilizador não-root, redes e health check no Compose, imagens no GHCR, GitHub Actions, Nginx e Cloudflare. A base de dados será uma evolução futura do projeto e está identificada dessa forma no guia.

Não pretende substituir a documentação oficial nem propor uma arquitetura universal de produção. É um laboratório orientado e uma base para continuar a aprender com contexto.

Se estás a começar, experimenta-o. Correções e sugestões são muito bem-vindas — e partilha-o com alguém que também esteja a dar os primeiros passos.

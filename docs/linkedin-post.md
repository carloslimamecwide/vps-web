# Criei um guia prático de DevOps para iniciantes

Quando comecei a explorar DevOps, encontrei muita documentação útil — mas espalhada por dezenas de páginas, vídeos e ferramentas. Faltava-me um recurso simples que ligasse os conceitos e mostrasse uma sequência prática para começar.

Por isso, documentei o que aprendi num guia gratuito orientado a iniciantes. Não é um standard de produção nem um curso enterprise: é um laboratório pedagógico e uma base para continuar a aprender com contexto.

O percurso de conceitos passa por Linux, SSH, Docker, Docker Compose, PostgreSQL básico, CI/CD, segurança e termina no conceito de reverse proxy (módulo 7.1). Quem quiser praticar de ponta a ponta tem um laboratório VPS completo (10 fases): redes Docker, Nginx, TLS com Cloudflare, base de dados, GitHub Actions e deployment.

Os exemplos aplicam o que o guia ensina: Dockerfile multi-stage com utilizador não-root, redes e health check no Compose, imagens no GHCR com tag `sha` e `latest`, GitHub Actions e proxy no VPS. Este próprio guia está pensado para correr com esse fluxo. No WebFusionLab, a base de dados é evolução futura — no lab do guia podes treinar o padrão na mesma.

Não pretende substituir a documentação oficial nem propor uma arquitetura universal de produção. Correções e sugestões são muito bem-vindas.

Se estás a começar, experimenta-o — e partilha-o com alguém que também esteja a dar os primeiros passos.
